POS El Tornillo

Prototipo integrado para registrar ventas y controlar existencias

Conectado a la base demo local
Entorno de demostración El catálogo es ficticio y se guarda en una base SQLite local. Este servidor se limita a este equipo; no usar datos reales ni exponerlo en una red. El catálogo, las existencias, los permisos y el canal de alertas siguen pendientes de confirmar con el dueño y bodega.
No se pudo conectar al servidor local. Ejecuta `python server.py` y abre esta página desde `http://127.0.0.1:8000/`.
