## Tareas para el participante

1. Buscar el producto `P-001` por código y luego localizar “martillo” por nombre.
2. Agregar dos unidades de un producto al detalle.
3. Intentar agregar una cantidad mayor al stock mostrado y explicar qué espera que ocurra.
4. Confirmar una venta con un nombre de vendedor de prueba.
5. Encontrar la venta recién ingresada en el historial filtrando por vendedor.
6. Revisar dónde aparece una alerta de stock bajo después de una venta de demostración.
